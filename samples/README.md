# Sample to try the skills on

`notes-system/`: a small notes feature shaped like a real product: an ASP.NET Core API with EF Core on
SQL Server, a React web client and a React Native client whose copy of the logic has drifted from the
web one (page size, retry delay, error messages, optimistic archiving). Make it a git repo
(`git init && git add -A && git commit -m base`), open Claude Code in it, and ask:
"Bring the notes feature into Ladder: the API in api/NotesApi and the client logic in web/src and mobile/src."
